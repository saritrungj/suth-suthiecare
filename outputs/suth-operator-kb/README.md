## สิ่งที่ทำระหว่างแปลงเป็น knowledge base

- **1 FAQ = 1 เอกสาร** ใส่ทั้งคำถามและคำตอบไว้ใน `content` เพราะ SUTH Operator สร้าง embedding จาก `content` เท่านั้น การมีคำถามอยู่ด้วยช่วยให้ค้นเจอง่ายขึ้น
- ลบ HTML และเลขลำดับหน้าคำถาม ("1. ", "2. ") ออก
- แก้คำผิดจากการคัดลอกจาก PDF เช่น ผู้เชี่ยวชำญ → ผู้เชี่ยวชาญ, ช้ำ ๆ → ช้า ๆ, หาากไม่ → หากไม่ รวมถึงคำที่ตกหล่น (ดูรายการใน `TYPO_FIXES`)
- สร้าง `keywords` ให้อัตโนมัติจากคำสำคัญในคำถาม/คำตอบ (ไม่เกิน 191 ตัวอักษรตามขนาดคอลัมน์)
- `metadata` ใช้รูปแบบเดียวกับข้อมูลที่นำเข้าจาก Excel เดิม (`source`, `category`, `sourceFile`) และเพิ่ม `sourceId` ให้ย้อนกลับไปหา `faqs.id` ได้ ไม่ได้ใส่ key ของ composition metadata จึงไม่ต้องผ่าน validation ชุดนั้น
- ถอดข้อความจากโปสเตอร์ PCU 2 รูปมาเขียนเป็นข้อความ และเพิ่มเอกสารที่เขียนเองอีก 6 รายการ: SUTHieCare คืออะไร/ขั้นตอนรับบริการ, แบบประเมินที่เปิดใช้, ช่องทางติดต่อคลินิกวัยรุ่น, เวลา PCU วันธรรมดา, เวลา PCU วันหยุด และ **เหตุฉุกเฉินด้านสุขภาพจิต** (1669 / 1323 / ER รพ.มทส.)

2. **เบอร์คลินิกวัยรุ่นไม่ตรงกัน** — footer เว็บใช้ `044-376555 ต่อ 6799`, แบบประเมิน STI ใช้ `044-376799`, แบบคลินิกวัยรุ่น (form #3) ใช้ `ต่อ 6122` ใน KB ใส่ 6799 / 044-376799 ไว้ ต้องยืนยันว่า 6122 ยังใช้อยู่หรือไม่
3. **เวลาทำแผลวันหยุดไม่ตรงกัน** — โปสเตอร์ #121 ระบุ 08.00–15.30 น. ส่วน #122 ระบุ 08.00–16.00 น. ใน KB ใช้ 16.00 น. ตาม #122 (อัปเดตทีหลัง)

## วิธีนำเข้า SUTH Operator

- นำเข้าทีละรายการผ่านหน้า `/knowledge` หรือส่ง `POST /api/knowledge` ด้วย session ที่มีสิทธิ์ create ตามรายการใน `suthiecare-faq-kb.json` ได้เลย (route นี้ embed ลง ChromaDB ให้อัตโนมัติ)
- `categoryId` ที่ใช้คือ `services`, `clinics`, `appointments` ซึ่งมีอยู่แล้วใน production
- ถ้ามีการแก้ FAQ ใน SUTHieCare ให้รัน `build_kb.py` กับ dump ใหม่ แล้วจับคู่เอกสารด้วย `metadata.sourceId`

## ข้อแนะนำสำหรับ AI live chat (ข้อมูลสุขภาพจิต/เพศสัมพันธ์)

- ถ้าข้อความมีสัญญาณเสี่ยงทำร้ายตนเอง (อยากตาย, ฆ่าตัวตาย, ทำร้ายตัวเอง) ให้ตอบด้วยเอกสารเหตุฉุกเฉินทันที และส่งต่อเจ้าหน้าที่ (handoff) ไม่ควรให้ RAG ตอบแบบทั่วไป ควรตั้ง exact keyword ใน `/keywords` เพิ่มเป็นชั้นป้องกันแรก
- คำถามที่ต้องวินิจฉัยหรือสั่งยา (เช่น "เป็นหนองในไหม", "ต้องกินยาอะไร") ให้ตอบตาม FAQ แล้วแนะนำให้ลงทะเบียน SUTHieCare หรือพบแพทย์ ไม่ควรให้ AI วินิจฉัยเอง
- เรื่อง PEP ต้องเน้นว่า "ภายใน 72 ชั่วโมง" และให้ไปโรงพยาบาลทันที
