ใช้งานได้ใน 4 ขั้นตอน

ขั้นที่ 1

เลือกบริการ

เลือกหน่วยบริการหรือคลินิก แล้วเลือกแบบประเมินที่ต้องการ

ขั้นที่ 2

ตอบแบบประเมิน

ตอบคำถามให้ครบ ข้อที่มีเครื่องหมาย * ต้องตอบ แล้วกดส่งคำตอบ

ขั้นที่ 3

รับผลและคำแนะนำ

ดูคะแนน ระดับผล และคำแนะนำเบื้องต้นได้ทันที

ขั้นที่ 4

ติดตามประวัติ

สมัครสมาชิกเพื่อดูผลย้อนหลังและการดูแลจากเจ้าหน้าที่

SUTHie Care · คู่มือผู้รับบริการ

ภาพรวมการใช้งาน ทำแบบประเมินได้โดยไม่ต้องเข้าสู่ระบบ (ยกเว้นแบบฟอร์มที่หน่วยงานกำหนดให้ต้องเข้าสู่ระบบ) ส่วนการดูประวัติย้อนหลังต้องมีบัญชีผู้รับบริการ
