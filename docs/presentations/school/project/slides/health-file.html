แฟ้มสุขภาพนักเรียน

ประวัติสุขภาพของนักเรียน อยู่ในที่เดียว

ผลประเมินทุกครั้ง สุขภาพใจ และสุขภาพกาย เรียงตามเวลา

บันทึก น้ำหนัก ส่วนสูง ความดัน สายตา สมรรถภาพ เห็นแนวโน้มเป็นกราฟ

ส่งต่อโรงพยาบาล เมื่อเกินกำลังโรงเรียน

SUTHie Care สำหรับโรงเรียน · 9 · ข้อมูลในภาพเป็นข้อมูลสมมติ

เปิดชื่อนักเรียนแล้วเห็นประวัติทั้งหมดในที่เดียว ทั้งผลประเมินสุขภาพใจและผลตรวจร่างกาย นักเรียนเองก็เห็นสุขภาพกายของตัวเองในบัญชี ถ้าเกินกำลังโรงเรียน ส่งต่อโรงพยาบาลผ่านเมนูส่งต่อระหว่างหน่วยงาน
